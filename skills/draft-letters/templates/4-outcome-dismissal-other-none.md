# Letter 4: outcome, dismissal, other disciplinary action, or no action

Adapted from Acas's template "Notice of disciplinary outcome letter: dismissal, disciplinary action or no action" (see `ATTRIBUTION.md`). Use only after the hearing, once the user has stated their decision. For a written or final written warning, use letter 3 instead.

**Keep only the one option that matches the user's decision**, and delete the option labels:
- **Option A:** no further action.
- **Option B:** other disciplinary action (for example demotion or a move to another role, as the user decided).
- **Option C:** dismissal, using `{{DISMISSAL-CONTENT}}`.

**Facts needed from the user:** the hearing date; the decision; for option B, the action and when it takes effect; for options B and C, the reasons; for option C, the last day of employment and the notice (a notice period, or without notice: their decision); who handles an appeal, how to send it and the period for appealing (their decision).

Copy the letter below exactly. Replace each `{{NAME}}` with that clause, copied exactly from `reference/code-version.md` ("Code-dependent letter clauses"). Fill [placeholders] only with what the user has said.

## Letter

```
DRAFT

[Today's date]

Dear [Employee name]

Notice of disciplinary outcome

You attended a disciplinary hearing on [date]. I am writing to inform you that:

[Option A] no further action will be taken against you.

[Option B] disciplinary action will be taken against you. The action will be: [the action you have decided, and when it takes effect]. The reasons for this disciplinary action are:
[reasons].

[Option C] {{DISMISSAL-CONTENT}}

{{APPEAL-RIGHT}}

Yours sincerely

[Signature]
[Name of manager]

Prepared with the help of an AI drafting tool and reviewed by [manager name].
```
