# Code version: the single place for Code-specific content

Every reference to a paragraph of the Acas Code, and every rule that depends on which version of the Code is in force, lives in this file and nowhere else. Skills and letter templates point here. When the revised Code takes effect, this file is swapped and the letter templates are re-checked.

**Status: filled for triage, the process guide and the letters.** The paragraph map, the wording used by triage, the wording used by the process guide (every stage), the Code-dependent letter clauses and the swap instructions are filled in.

The statutory right to be accompanied (the legislation itself, not the Code) is in `right-to-be-accompanied.md`. It is not part of the Code, so it is not swapped with this file.

The plain-English explanations that skills give instead of quoting this file are in `plain-english.md`. When this file is swapped, re-check `plain-english.md` against the new wording.

Code wording in this file is quoted exactly from the Acas Code page, read directly on 15 November 2026. Contains public sector information licensed under the Open Government Licence v3.0 (see `ATTRIBUTION.md`).

## Version in use

- **Code:** Acas Code of Practice on disciplinary and grievance procedures
- **Issued under:** section 199 of the Trade Union and Labour Relations (Consolidation) Act 1992
- **In force:** 11 March 2015 (replaced the 2009 Code)
- **Applies to:** Great Britain (England, Wales and Scotland)

## Draft revised Code (not yet in force)

- **Status:** consulted on from 30 July to 23 September 2026. Acas expects it to take effect in 2027; no date has been set.
- **Status checked directly on 15 November 2026:** the draft page says "The consultation closed on 23 September 2026. We're in the process of reviewing responses." Its laying and commencement dates are still "[insert date]".

- **Label:** "good practice from Acas's draft revised Code (2026 consultation)". The label goes in the sign-off checklist beside the line, **never inside the letter** (step 5, decision 5).

## Wording used by triage

**Shown only on request.** Replies explain with `plain-english.md`. Show these passages only when the user asks to see the exact Acas wording. Then quote them word for word, inside quotation marks, and say they come from the Acas Code. Do not add paragraph numbers in replies to the user.

**Informal resolution (Foreword):**
> "Many potential disciplinary or grievance issues can be resolved informally. A quiet word is often all that is required to resolve an issue. However, where an issue cannot be resolved informally then it may be pursued formally."

**Keeping a record (Foreword):**
> "Employers would be well advised to keep a written record of any disciplinary or grievances cases they deal with."

**Elements of fairness in a formal process (para 4), for general information:**
> "Employers should carry out any necessary investigations, to establish the facts of the case."
> "Employers should inform employees of the basis of the problem and give them an opportunity to put their case in response before any decisions are made."
> "Employers should allow employees to be accompanied at any formal disciplinary or grievance meeting."
> "Employers should allow an employee to appeal against any formal decision made."

**Investigation (para 5), for general information:**
> "It is important to carry out necessary investigations of potential disciplinary matters without unreasonable delay to establish the facts of the case."

**Suspension (para 8):**
> "In cases where a period of suspension with pay is considered necessary, this period should be as brief as possible, should be kept under review and it should be made clear that this suspension is not considered a disciplinary action."

**Misconduct: the usual outcome (para 19):**
> "Where misconduct is confirmed or the employee is found to be performing unsatisfactorily it is usual to give the employee a written warning."

The Code gives no list of examples of ordinary misconduct. The examples in `plain-english.md` (entry TM) are Fair Hearing's own wording, approved by Dan on 16 November 2026. Never present them as the Code's, and never add others.

**Gross misconduct (paras 23 and 24):**
> "Some acts, termed gross misconduct, are so serious in themselves or have such serious consequences that they may call for dismissal without notice for a first offence. But a fair disciplinary process should always be followed, before dismissing for gross misconduct."
> "Disciplinary rules should give examples of acts which the employer regards as acts of gross misconduct. These may vary according to the nature of the organisation and what it does, but might include things such as theft or fraud, physical violence, gross negligence or serious insubordination."

## Wording used by the process guide

**Shown only on request.** Replies explain with `plain-english.md`. Show these passages only when the user asks to see the exact Acas wording. Then quote them word for word, inside quotation marks, and say they come from the Acas Code. Do not add paragraph numbers in replies to the user. Never quote the draft revised Code section above in the process guide.

Each stage lists the wording to quote for that stage. A passage may be quoted in part, but only as whole sentences, never with words changed, added or left out inside a sentence.

### Informal route

**Informal resolution (Foreword):**
> "Many potential disciplinary or grievance issues can be resolved informally. A quiet word is often all that is required to resolve an issue. However, where an issue cannot be resolved informally then it may be pursued formally."

**Keeping a record (Foreword):**
> "Employers would be well advised to keep a written record of any disciplinary or grievances cases they deal with."

### Elements of fairness (para 4, in full; for the overview)

> "Employers and employees should raise and deal with issues promptly and should not unreasonably delay meetings, decisions or confirmation of those decisions."
> "Employers and employees should act consistently."
> "Employers should carry out any necessary investigations, to establish the facts of the case."
> "Employers should inform employees of the basis of the problem and give them an opportunity to put their case in response before any decisions are made."
> "Employers should allow employees to be accompanied at any formal disciplinary or grievance meeting."
> "Employers should allow an employee to appeal against any formal decision made."

### Size and resources (para 3; the matching plain-English entry is PZ)

> "Where some form of formal action is needed, what action is reasonable or justified will depend on all the circumstances of the particular case. Employment tribunals will take the size and resources of an employer into account when deciding on relevant cases and it may sometimes not be practicable for all employers to take all of the steps set out in this Code."

Quote it without comment. Never say what the user should do as a result, and never present it as permission to skip a step.

### Stage 1: Investigation (paras 5 to 7; para 8 if suspending)

> "It is important to carry out necessary investigations of potential disciplinary matters without unreasonable delay to establish the facts of the case. In some cases this will require the holding of an investigatory meeting with the employee before proceeding to any disciplinary hearing. In others, the investigatory stage will be the collation of evidence by the employer for use at any disciplinary hearing."

> "In misconduct cases, where practicable, different people should carry out the investigation and disciplinary hearing."

> "If there is an investigatory meeting this should not by itself result in any disciplinary action. Although there is no statutory right for an employee to be accompanied at a formal investigatory meeting, such a right may be allowed under an employer's own procedure."

**Suspension (para 8), only if the user is suspending or asks about it:**
> "In cases where a period of suspension with pay is considered necessary, this period should be as brief as possible, should be kept under review and it should be made clear that this suspension is not considered a disciplinary action."

### Stage 2: Invitation (paras 9 and 10; the right to be accompanied, paras 13 to 16)

> "If it is decided that there is a disciplinary case to answer, the employee should be notified of this in writing. This notification should contain sufficient information about the alleged misconduct or poor performance and its possible consequences to enable the employee to prepare to answer the case at a disciplinary meeting. It would normally be appropriate to provide copies of any written evidence, which may include any witness statements, with the notification."

> "The notification should also give details of the time and venue for the disciplinary meeting and advise the employee of their right to be accompanied at the meeting."

**The right to be accompanied (paras 13 to 16):**

> "Workers have a statutory right to be accompanied by a companion where the disciplinary meeting could result in:"
> "a formal warning being issued; or"
> "the taking of some other disciplinary action"
> "the confirmation of a warning or some other disciplinary action (appeal hearings)"

> "The statutory right is to be accompanied by a fellow worker, a trade union representative, or an official employed by a trade union. A trade union representative who is not an employed official must have been certified by their union as being competent to accompany a worker. Employers must agree to a worker's request to be accompanied by any companion from one of these categories. Workers may also alter their choice of companion if they wish. As a matter of good practice, in making their choice workers should bear in mind the practicalities of the arrangements. For instance, a worker may choose to be accompanied by a companion who is suitable, willing and available on site rather than someone from a geographically remote location."

> "To exercise the statutory right to be accompanied workers must make a reasonable request. What is reasonable will depend on the circumstances of each individual case. A request to be accompanied does not have to be in writing or within a certain timeframe. However, a worker should provide enough time for the employer to deal with the companion's attendance at the meeting. Workers should also consider how they make their request so that it is clearly understood, for instance by letting the employer know in advance the name of the companion where possible and whether they are a fellow worker or trade union official or representative."

> "If a worker's chosen companion will not be available at the time proposed for the hearing by the employer, the employer must postpone the hearing to a time proposed by the worker provided that the alternative time is both reasonable and not more than five working days after the date originally proposed."

**Foreword note on postponement (on request, when postponement comes up; plain-English entry PP):**
> "When dealing with requests to postpone a disciplinary hearing to accommodate the attendance of a worker's companion, readers of the Code will wish to be aware of the Employment Appeal Tribunal judgement in the case of Talon Engineering Ltd v Smith. Guidance on this issue is contained in Discipline and grievances at work: the Acas guide."

Do not summarise or explain the case. Fair Hearing has not adapted the Acas guide.

### Stage 3: Hearing (paras 11 and 12; para 17; para 25)

> "The meeting should be held without unreasonable delay whilst allowing the employee reasonable time to prepare their case."

> "Employers and employees (and their companions) should make every effort to attend the meeting. At the meeting the employer should explain the complaint against the employee and go through the evidence that has been gathered. The employee should be allowed to set out their case and answer any allegations that have been made. The employee should also be given a reasonable opportunity to ask questions, present evidence and call relevant witnesses. They should also be given an opportunity to raise points about any information provided by witnesses. Where an employer or employee intends to call relevant witnesses they should give advance notice that they intend to do this."

**The companion's role (para 17):**
> "The companion should be allowed to address the hearing to put and sum up the worker's case, respond on behalf of the worker to any views expressed at the meeting and confer with the worker during the hearing. The companion does not, however, have the right to answer questions on the worker's behalf, address the hearing if the worker does not wish it or prevent the employer from explaining their case."

**Failure to attend (para 25):**
> "Where an employee is persistently unable or unwilling to attend a disciplinary meeting without good cause the employer should make a decision on the evidence available."

### Stage 4: Outcome (paras 18 to 24)

> "After the meeting decide whether or not disciplinary or any other action is justified and inform the employee accordingly in writing."

> "Where misconduct is confirmed or the employee is found to be performing unsatisfactorily it is usual to give the employee a written warning. A further act of misconduct or failure to improve performance within a set period would normally result in a final written warning."

> "If an employee's first misconduct or unsatisfactory performance is sufficiently serious, it may be appropriate to move directly to a final written warning. This might occur where the employee's actions have had, or are liable to have, a serious or harmful impact on the organisation."

**What a warning must contain (para 21):**
> "A first or final written warning should set out the nature of the misconduct or poor performance and the change in behaviour or improvement in performance required (with timescale). The employee should be told how long the warning will remain current. The employee should be informed of the consequences of further misconduct, or failure to improve performance, within the set period following a final warning. For instance that it may result in dismissal or some other contractual penalty such as demotion or loss of seniority."

**Dismissal (para 22):**
> "A decision to dismiss should only be taken by a manager who has the authority to do so. The employee should be informed as soon as possible of the reasons for the dismissal, the date on which the employment contract will end, the appropriate period of notice and their right of appeal."

**Gross misconduct (paras 23 and 24):** use the gross misconduct wording in "Wording used by triage" above.

Where these passages mention performance, quote them unchanged, but never apply them to a performance case. Fair Hearing covers conduct only.

### Stage 5: Appeal (paras 26 to 29)

> "Where an employee feels that disciplinary action taken against them is wrong or unjust they should appeal against the decision. Appeals should be heard without unreasonable delay and ideally at an agreed time and place. Employees should let employers know the grounds for their appeal in writing."

> "The appeal should be dealt with impartially and, wherever possible, by a manager who has not previously been involved in the case."

> "Workers have a statutory right to be accompanied at appeal hearings."

> "Employees should be informed in writing of the results of the appeal hearing as soon as possible."

### Not used by the process guide

These parts of the Code page are left out on purpose:
- **The Foreword's lines on tribunals adjusting awards by up to 25 per cent:** they edge into claim value, which Fair Hearing never gives.
- **The Foreword's line on handling whistleblowing under a separate procedure:** whistleblowing is red flag 3.
- **The Foreword's paragraph on mediation and independent third parties:** not part of this step's informal route.
- **Paras 30, 31 and 46** (union representatives, criminal charges, a grievance raised during a disciplinary): each matches a red flag (4, 7 and 5), so the case has already stopped before they could apply. They may be quoted only as general information after a stop.

## Code-dependent letter clauses

Used only by the `draft-letters` skill. Each template in `skills/draft-letters/templates/` marks where a clause goes with its name in double braces, for example `{{EVIDENCE}}`. The skill copies the clause text below exactly, then fills its [placeholders] only with what the user has said. Anything the user hasn't said stays as a [placeholder]. Never add paragraph numbers, or the word "Acas", to a letter.

The wording is adapted from Acas's letter templates (listed in `ATTRIBUTION.md`), with the changes recorded in `docs/sources.md`. The right to be accompanied is statute, not Code, so the companion sentence is in `right-to-be-accompanied.md` ("Letter clause"), not here.

| Clause | Used in letters | What it meets (2015 Code) |
|---|---|---|
| `TIME-VENUE` | 1, 2 | Para 10: time and venue |
| `ALLEGATION` | 1, 2 | Para 9: sufficient information about the alleged misconduct |
| `INFORMAL-STEPS` | 1, 2 | Draft revised Code para 32 (good practice, not yet in force) |
| `EVIDENCE` | 1, 2 | Para 9: copies of written evidence |
| `CONSEQUENCES-WARNING` | 1 | Para 9: possible consequences |
| `CONSEQUENCES-DISMISSAL` | 2 | Para 9: possible consequences |
| `WARNING-CONTENT` | 3 | Para 21: what a warning must contain |
| `DISMISSAL-CONTENT` | 4 | Para 22: reasons, the date the contract ends and the notice |
| `APPEAL-RIGHT` | 3, 4 | Paras 4, 22 and 26: the right of appeal; grounds in writing |

### TIME-VENUE
```
I am writing to tell you that you are required to attend a disciplinary hearing on [date] at [time] which is to be held at [location].
```

### ALLEGATION
If the user has a written disciplinary procedure, keep the bracketed phrase and put in its name. If they have none, or haven't said, ask; if they have none, leave the phrase out.
```
At this hearing we will consider disciplinary action against you[, in line with [name of your disciplinary procedure]]. This is with regard to:
[details of the alleged misconduct]
```

### INFORMAL-STEPS (draft revised Code; label it in the checklist only)
Use the first version if informal steps were taken, the second if none were. The reason is the user's own; never suggest one.
```
Before this, the following steps were taken to try to resolve the concern informally: [steps taken].
```
```
No steps have been taken to resolve the concern informally, because [reason, in your words].
```

### EVIDENCE
```
I enclose the following evidence:
[list of enclosed evidence]
```

### CONSEQUENCES-WARNING
The consequences are the user's own decision, stated by them. Never suggest one.
```
The possible consequences arising from this hearing might be:
[possible consequences, as you have decided them].
```

### CONSEQUENCES-DISMISSAL
The consequences are the user's own decision, stated by them. Never suggest one. List each consequence the user states on its own line; one of them is dismissal.
```
The possible consequences arising from this hearing are:
[each possible consequence you have decided, one per line, including dismissal]
```

### WARNING-CONTENT
Every period and consequence is the user's; never suggest one.
```
This warning will be placed in your personal file but will be disregarded for disciplinary purposes after a period of [number] months, provided your conduct improves.

a) The nature of the misconduct was:
[details of the misconduct]

b) The change in conduct expected is:
[details of the change required]

c) The timescale within which the change is required is:
[timescale]

d) The likely consequence of further misconduct within this period is a further disciplinary procedure that could lead to [the consequence you have decided, for example a final written warning or dismissal].
```

### DISMISSAL-CONTENT
Use the notice line the user's decision matches. The last day and the notice are the user's; never calculate either.
```
you will be dismissed and your last day of employment with the company will be [date]. The reasons for your dismissal are:
[reasons].

[Your notice period is [notice period, as you have decided it].] / [You are being dismissed without notice.]
```

### APPEAL-RIGHT
The person, the method and the period are the user's; never suggest a period.
```
You have the right of appeal against this decision. If you would like to appeal, please [write to / email] [name or role of the person handling the appeal] at [email address or postal address] within [period you have set] of receiving this letter, setting out your grounds of appeal.
```

## How to swap versions

When Acas's revised Code takes effect:

1. **Confirm the date.** Read the commencement order and Acas's announcement directly, and record both in `docs/sources.md` with their URLs and fetch dates.
2. **Check the licence.** Check the new Code page for an "except where otherwise stated" exclusion and record the result. If it is excluded, stop and tell Dan.
3. **Replace this file's Code content.** Update "Version in use", the paragraph map, and every quoted passage, copied word for word from a direct download of the new Code. Keep the section headings ("Wording used by triage", "Wording used by the process guide" and its stage headings), so the skills still find what they need.
4. **Remove the draft revised Code section**, or replace it with what the final Code says. Re-check the invitation letter's informal-steps line against the final wording and drop the "draft" label.
5. **Script-check** every quoted passage against the download, as was done for the 2015 Code, and record the result.
6. **Leave `right-to-be-accompanied.md` alone** unless the legislation itself has changed. It is statute, not the Code.
7. **Re-check** the letter templates against Acas's updated letters, and the "Code-dependent letter clauses" above against the new Code (for example what a warning or a dismissal letter must contain). Keep the clause names, so the templates still find them. Update `ATTRIBUTION.md`.
8. **Run the full test regression** (triage, red-flags, process guide, letters) before committing.
9. **Transition:** decide with Dan how to treat cases that started under the 2015 Code and are still running on the change date. Log it as an open item until decided.
